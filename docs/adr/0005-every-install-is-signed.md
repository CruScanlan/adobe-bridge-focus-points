# Every install is code-signed, even in development

Bridge 2026 (CEP 12) will not load an unsigned extension: dialog panels show "Unable to load" and an `Embedded` panel hard-crashes Bridge, with only "Signature verification failed" in the CEP log. So every install, including every dev iteration, goes through `tools/sign-install.sh`, which self-signs with `tools/cert.p12`. A self-signed certificate is sufficient on its own: Bridge loads the extension with no `PlayerDebugMode` set, which is how it has always run on the dev machine (the value was only ever written to the Claude app's private registry hive, never the real one). Whether real debug mode would let an unsigned extension load is untested. Editing any installed file invalidates the signature, so re-run the script after every change. A "crashing panel" after an edit is a missing re-sign before it is anything else.
